# 청산 배점 수정: 0인 구간을 순위에서만 제외

## 적용 내용

- 현재 5분 청산 속도를 과거 청산 속도 중 양수인 구간과 비교한다.
- LONG과 SHORT의 비교 분포는 각각 따로 만든다. 상대 방향 표본 부족으로 현재 방향을 막지는 않는다.
- 양수 표본 20개 이상, 기존 시간 기준 6시간 이상을 모두 만족해야 순위를 계산한다.
- 20개는 임시 최소 표본 기준이며 통계적 신뢰도를 보장하지 않는다. 설정은 `liquidation_speed_min_positive_windows`이다.
- 기존 백분위 배점표 0~6점은 유지한다. 양수여도 하위 30%이면 0점이다. 동일값은 기존처럼 이하 순위를 적용한다.
- 총 청산 활동도 순위에도 동일하게 양수 구간 기준을 적용한다. 기존 청산 보너스의 조건과 최대 1점은 유지한다.
- 청산이 없으면 점수 0. 양수 표본 부족 시 점수 0이며, 다른 조건을 통과한 경우 `insufficient_positive_history`로 기록한다.

## 바뀌지 않은 부분

원본 데이터, 0 구간 기록, 평균, 표준편차, 시간 순서에 따른 속도 변화 및 z값은 그대로 유지한다.
직전 5분보다 증가, 기존 평균 초과, 방향 불균형 조건도 변경하지 않았다.
다른 구성요소, 주문 코드, 진입 기준, 손절 및 익절 조건은 수정하지 않았다.
다만 청산 점수와 청산 활동 보너스가 달라져 총점 및 실제 진입·방향 전환 결과는 달라질 수 있다.
API 호출 추가 및 DB schema 변경은 없다.

## 기록과 버전

- 전략 버전: `market_state_engine_v3_liquidation_positive_rank`
- 기존 호환용 `scoring_mode=speed_5m_v1`은 유지하고 `ranking_method=positive_windows_v2`를 추가했다.
- 구간별 `positive_reference_count`, `rank_ready` 추가.
- `minimum_positive_windows`, `activity_speed_percentile`, `activity_positive_reference_count`, `activity_rank_ready` 추가.
- 기존 indicators JSON에 저장되며 과거 기록은 변경하지 않는다.
- 새 전략의 예측 비교 표본은 다시 축적해야 한다. 실행 시 `--strategy-version`을 이전 값으로 강제 지정하지 않는다.
